# Snake Water Gun Game

This is a simple game written in Python where you play against the computer. The choices are:
- Snake (s)
- Water (w)
- Gun (g)

## How to Play:
1. Run the `snake_water_gun.py` script.
2. Enter your choice: Snake, Water, or Gun.
3. The computer will choose randomly, and the game will tell you if you won, lost, or if it was a tie.

## Requirements:
Python 3.x
